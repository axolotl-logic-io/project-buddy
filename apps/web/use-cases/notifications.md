# Installed app

The conventions for these cases are in [the index](README.md#conventions).

## use_case_install_app

The user puts Project Buddy on their phone's Home Screen and opens it like an app.

- **Prerequisites:** none.
- **Steps:**
  - The user opens the site on their phone: in Chrome on Android, or in Safari on an iPhone.
  - The user installs it: **Install app** in Chrome's menu, or **Add to Home Screen** in Safari's Share menu.
  - The user opens Project Buddy from its icon on their Home Screen.
- **Outcome:** their Home Screen shows Project Buddy's icon, named "Project Buddy". It opens at the landing page in a window of its own, with no address bar, which takes them to sign in when the user isn't signed in. The splash screen and the bar at the top take the default theme's background, light or dark as their phone is set. Every page comes from the site, as in the browser: nothing the user sees is an old saved copy.
