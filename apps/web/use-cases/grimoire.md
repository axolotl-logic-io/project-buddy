# Grimoire

The Grimoire offers the built-in rites, Capture and Brainstorm, and the user's own rites. Capture confirms each message. Brainstorm replies with brainstorming cues that help the user think of more. Either can be performed on any list. Built-in pages are read-only and offer Make a copy. Own rites can be created, edited, copied and forgotten.

## use_case_grimoire_page

- **Goal:** Find built-in and own rites from the main menu.
- **Steps:** Open the Grimoire under Places. Type in Find a rite, or press "/" to reach it from anywhere but a field. Choose All, Built-in, Yours or Forgotten. Choose a rite's row to open it. Choose New rite in the trail band to make a private rite.
- **Outcome:** All, Built-in and Yours list only built-ins and the acting user's own active rites; forgotten rites appear only under Forgotten. Each row shows the rite's seal, name, a Built-in tag for built-ins, its first message on one line with placeholders set apart, the day it was last edited or forgotten, and its count of replies. The search matches names and first messages as the user types; Escape or Clear empties it. Each tab counts the rites that match the search, and the search and tab stay in the address. Built-ins come first, then own rites by name; forgotten rites come most recently forgotten first. Empty collections and unmatched searches are explained. There is no Workshop or Constructs tab.

## use_case_customize_rite

- **Goal:** Write an own rite's replies without changing performances already under way.
- **Steps:** Choose New rite in the Grimoire, or open a rite and make a copy. Edit its name, its first message and its reply list. Save, or Cancel to restore the saved fields. Try the rite by performing it on a list ([`use_case_perform_rite`](performances.md#use_case_perform_rite)).
- **Outcome:** Only the owner can edit the rite. A rite has one reply list, which supports adding, editing, removing and reordering, with at least one reply. Each reply can prompt the user with a brainstorming or planning cue. Replies can use placeholders for the rite's name, the list's name and nouns, the message's text and the acting user's name ([`use_case_set_name`](accounts.md#use_case_set_name)). A rite needs a first message, which opens each performance of it and can use placeholders for the rite's name and the list's name. The site writes the messages for stopping and for failed messages from the rite's name and the list's words. Built-in and forgotten rites show their first message and replies as read-only text. Browser drafts survive navigation until saved or cancelled, unless a newer save makes them outdated. Save reveals and focuses invalid fields. The active performance keeps its rite snapshot when the source changes. The detail page's header shows the rite's seal, whether it is a built-in, own or forgotten rite, its count of replies and when it was edited or forgotten, with Make a copy and Forget, or Restore and Delete forever once forgotten. A legend beneath the messages explains each placeholder. The Grimoire's Forgotten tab also restores or deletes forgotten rites. Breadcrumbs lead from Home through the Grimoire to the rite's name.
