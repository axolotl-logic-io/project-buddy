# Installed app

Project Buddy can be added to a phone's Home Screen. In Chrome on Android,
choose **Install app**. In Safari on iPhone, choose **Add to Home Screen**
from the Share menu, then open the Home Screen icon.

The installed app is the same online site in its own window. Every launch reaches the site and requires sign-in when the session has ended. Nothing is cached for offline use.

The logo and app icons show a tilted, angular hourglass inside a gear, with unequal chambers that make the mark asymmetric.

The site registers no service worker, requests no notification permission
and sends no notifications.

Physical Home Screen installation needs manual device validation.
