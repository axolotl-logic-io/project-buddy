# Experiment recipes

These archived recipes extend the [#773 capture recipes](../../773/recipes/) and existing server/browser fixture kits. They describe #796 evidence; #797 owns the maintained audit command and schema. They are not a second supported audit CLI.

Copy recipes without the `.txt` suffix into `/tmp/pb-796` and run from an isolated worktree. Keep the pinned Chrome, Puppeteer and Lighthouse versions in the report. Create an isolated `.env.test` through the existing test-environment kit, with mock models and a unique test database and port. Never print it. Seed through the existing #773/test-data kits, then `seed-mixed.mts` and `seed-stream.mts`. Copy these seed modules into `apps/web` for their repository-relative kit imports, invoke them with the supplied test environment, and remove the temporary modules afterward. `extend.mts` is the historical plain 20-message fixture used before the mixed replacement; do not use it for the final mixed cohort. The private mode-0600 session file is an input only and must never enter an artifact. Recipe paths, session properties and build snapshot paths describe this experiment; adapt them together for another isolated run.

Build each source with the normal production command under the shared validation lock, using the supplied test environment. Keep **real copied** `.next` directories for both snapshots; symlinked serving failed in this experiment. Matrix/confirmation/stream wrappers copy the selected snapshot, start the server and await its shutdown inside the lock. Each pair alternates order. Do not run a server-kit reset while capture fixtures remain in use.

The main matrix and cold extensions form 132 observations. Mixed confirmation deliberately prewarms server document modules and stays a separate 20-observation cohort. Controlled streams use six distinct conversations. The anchor probe appends to the already-completed first stream conversation, so run it only after both first streams finish. Bounded rendering uses the renderer build plus an injected diagnostic stylesheet. The Home artwork probe extends observation to ten seconds; Lighthouse is a separate warm, simulated-throttling profile. Neither is pooled with the applied phone matrix. Build optimization is a temporary config experiment with an exit trap restoring the original file.

Sanitize before archive. The collector exports static resource/operation categories and geometry only. Strip trace arguments and all screenshot events. Preserve failed/cancelled stage provenance. After assembling the compressed cohorts, run the archived strict validator and its negative cases, then the reducer, attribution recipe and chart against the artifact directory. The capture, reducer and schema files are intentionally versioned with this experiment so later maintained-runner changes cannot silently alter old results.

After every capture and supplemental diagnostic has finished, run affected server tests through the guarded test database command, remove the private session file and leave no owned server/browser process running. Do not drop shared lane resources.
