# Place icons

The shared `Icon` component uses named imports from `lucide-react` for Plan
and editing controls. Atlas-only symbols were removed with Home. Other
interface symbols keep their existing drawings.

Shared navigation and editing controls use the icon component. Icons inherit
the surrounding text color and the `.icon` size role. They are decorative,
hidden from assistive technology and unable to receive focus; visible labels
carry the meaning. Construct artwork and generated images use their own
rendering primitives. The retired Home atlas has no artwork or icon map.
