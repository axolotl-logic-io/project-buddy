# Place icons

The shared `Icon` component draws a few symbols, for Tasks and editing controls, from [Lucide](https://lucide.dev) through named imports from `lucide-react`. Other interface symbols keep their own drawings. Construct artwork and saved images use their own rendering primitives.

Icons inherit the surrounding text color and size. They are decorative, hidden from assistive technology and unable to receive focus, so visible labels carry the meaning.

The public Credits page links to Lucide and the full package license at `apps/web/public/licenses/lucide.txt`. Keep the copied license when updating the dependency.
