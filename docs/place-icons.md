# Place icons

The shared `Icon` component uses named imports from `lucide-react` for Tasks
and editing controls. Other interface symbols keep their own drawings.

Shared navigation and editing controls use the icon component. Icons inherit
the surrounding text color and the `.icon` size role. They are decorative,
hidden from assistive technology and unable to receive focus; visible labels
carry the meaning. Construct artwork and saved images use their own
rendering primitives.

The public Credits page links to Lucide and the full package license at `apps/web/public/licenses/lucide.txt`. Keep the copied license when updating the dependency.
