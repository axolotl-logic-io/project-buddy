# Quest overview

Opening a quest opens its overview. It shows the quest's status, starting context when available, and Next task. Next task is the first open task and can be checked off from the overview. Dailies puts Start Day, Undo Start Day when available, and Day grid in that place.

The overview links to Tasks, Ideas, Quick Notes, Progress, Spells & status, and Members. Each section has an Overview link. Owners and accepted members can edit the collections, change quest status and manage members from these pages. Dailies remains personal. These actions save directly to the quest.

## Spell conversation

Cast a built-in or own spell from Spells & status. The spell conversation opens above the section content and stays available as you go between sections. Each message goes into the active spell's Tasks or Ideas destination and receives the spell's reply. Stop ends the spell and removes the conversation and composer. The site requires an active spell to accept a message.

## Timer

The Timer docks to the right edge on wide screens. Use the sidebar button to collapse or reopen it. On phones the button opens the Timer in a modal drawer. Work for and Break for use the presets from the [Timer](timer.md). Start begins a work period in place. The schedule continues while the sidebar is closed or as you move between sections of the same quest.
